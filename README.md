## 🚀 Project

### Prepper
> 레시피 링크 정리의 새로운 방법

YouTube, Shorts, Blog 등 여러 곳에 흩어진 레시피 링크를 입력하면  
레시피 정보를 추출하고 정리해 **나만의 요리 노트로 만들어주는 서비스**입니다.

1인 개발로 진행하며 기획부터 Frontend, Backend, Mobile App까지 직접 구현했습니다.

**Web / Mobile**

`React` `TypeScript` `Expo` `Express` `Supabase`

🔗 [Prepper Repository](https://github.com/YoungSeungJang/prepper)
